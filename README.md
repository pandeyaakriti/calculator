# math.me

A small, interactive calculator built n for the WLiT Fellowship 2026.

I wanted to take a simple HTML, CSS, and JavaScript task and turn it into something that feels a little more personal rather than building a standard four-function calculator.


The goal was to build a calculator using:
- HTML
- CSS
- JavaScript

The project is intentionally built with vanilla web technologies without frameworks or libraries.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculations
- Decimal numbers
- Clear and delete functionality
- Keyboard support
- Interactive button 
- Small UI interactions and personality details

## Tech Stack

- HTML5 — structure
- CSS3 — styling, layout, and animations
- Vanilla JavaScript — calculator logic and interactions

No frameworks or external libraries were used.

## Why I Built It This Way

A calculator is a fairly ordinary programming exercise, so I used it as an opportunity to experiment with something beyond functionality.

The idea was to explore how a familiar tool can feel more engaging through small details in interaction, visual design, and feedback while still keeping the underlying implementation simple and understandable.
